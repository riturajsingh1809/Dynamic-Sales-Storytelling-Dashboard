# Dynamic Sales Storytelling Dashboard

## Project Overview

This project focuses on building an interactive and decision-focused sales dashboard with dynamic filters and data storytelling.

The dashboard helps users analyze sales, profit, orders and quantity across different regions, categories, products and customer segments.

## Objective

The objective is to transform raw business data into a clean, validated and interactive dashboard that supports quick business analysis and decision-making.

## Tools & Technologies

* *Excel* – Data Cleaning and Preparation
* *Python / Google Colab* – Data Analysis
* *Pandas & NumPy* – Analysis and aggregation
* *Tableau* – Interactive Dashboard and Data Storytelling

## Project Workflow

*Raw Dataset → Excel Data Cleaning → Python Analysis → Tableau Dashboard → Business Insights*

Data cleaning was performed in *Excel*, including duplicate handling, missing-value treatment, formatting and data standardization.

Python and Google Colab were used for analytical calculations and generating summarized analysis results.

Tableau was used to create the final interactive dashboard with filters and drill-down views.

## Dashboard Features

* Total Sales KPI
* Total Profit KPI
* Total Orders KPI
* Total Quantity KPI
* Regional Performance
* Category Performance
* Sales & Profit Trend
* Product Performance
* Customer Segment Analysis
* Region vs Category Analysis
* Interactive filters for Date, Region, Category and Customer Segment

## Key Outcome

The final dashboard provides an interactive view of business performance and allows users to explore the data from different perspectives using filters and detailed performance views.
